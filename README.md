# literature-verify

文献、公式、数值与中文文稿质量核查 skill：**只给证据，不改稿**。

两件事共用一套骨架：

1. **事实核查**：文献书目 / 经典公式 / 数值常数 / 单位 / 出处（作者、年份、刊、卷、页、DOI/arXiv/ISBN）；
2. **文本质量核查**：自造词、不合逻辑的结论、AI 味语句。

流程固定为：拆条目 → 逐条三档 → 填全出处字段 → 抓取校验（文件头嗅探）→ 出报告。

## 安装

### DSHM

DSHM 的 `$DSH_HOME/skills/` 是**一个技能一个 `.md` 文件**（扁平目录）：

```bash
cp SKILL.md "$DSH_HOME/skills/literature-verify.md"
```

重开 DSHM（或新会话）后即可使用。

### Claude Code

```bash
mkdir -p ~/.claude/skills/literature-verify
cp SKILL.md ~/.claude/skills/literature-verify/SKILL.md
```

本 skill 是纯 Markdown 指令，核心动作是检索、读原文、独立重算与写报告，不依赖特定运行时。

## 适用场景

- 核对论文 / 教材里的经典公式、数值、常数、定义，找出处；
- 给讲义补引用、做文献综述前核实书目；
- 查 DOI / arXiv 编号是否真实、卷页是否正确；
- 审稿或自审中文文稿：查自造词、逻辑断点、AI 味；
- 核查下载到的 PDF 是不是真的 PDF（HTML / captcha / 0 字节伪装）。

**不做**：重写文章、代写文献综述、排版与公式渲染、替作者定稿。

## 核查三档

每条待核查内容都必须落到下面三档之一，并写清依据等级：

| 结论档 | 含义 | 依据要求 |
|---|---|---|
| **已核实** | 直接读到原文或权威数据库，字段齐全 | 原文直读可 1 个来源；否则至少 2 个独立来源一致 |
| **存疑** | 有线索但没读到原文，或来源冲突、版次/式号不确定 | 写清「核到什么程度」与冲突点 |
| **未找到** | 检索后仍未定位到可靠出处 | 写进「未核实清单」，交给用户 |

依据等级（从高到低）：**原文直读 > 权威数据库（出版社 / ADS / Crossref / arXiv）> 二手来源 > 独立推算**。

三条铁律：

1. 没读到原文 / 权威数据库，就标「存疑」或「未找到」，**绝不写「已核实」**；
2. 禁止编造文献、DOI、页码、式号——宁可少引，不可假引；
3. 教材的「简化」与「真错」分开：简化写清成立条件与误差，真错才进 P0。

报告同时给出严重度：**P0** 事实错误（必改）、**P1** 逻辑 / 术语（建议改）、**P2** 文风（可选改，附改写示例）。

## 依赖

| 能力 | 说明 |
|---|---|
| 联网检索 / 抓取 | 任意可用的搜索与 HTTP 抓取工具（DSHM 内置 `web_search` / `web_fetch`，或其他等价工具） |
| 读 PDF / PPTX 原文 | 可选。DSHM 可用 `ohos-doc-read`；其他环境用 `pdftotext`、PyMuPDF 等，**不要凭记忆引页码** |
| 数值重算 | Python（必须独立重算，禁止心算、禁止抄中间结果） |
| docx 交付 | 可选，`md2docx` 负责排版；本 skill 只给出处字段与核查结论 |
